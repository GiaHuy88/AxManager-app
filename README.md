🚀 AxManager

AxManager is an Android gaming utility designed to help users manage and apply gaming modules, performance tweaks, and device optimizations with a simple interface.

It can be used with Shizuku to provide advanced Android functionality without requiring root access.

---

✨ Features

- 🎮 Gaming performance optimization
- ⚡ Apply gaming modules and tweaks
- 📱 Android device optimization
- 🚫 No Root support with Shizuku
- 🔧 Easy module management
- 🧹 Quick system optimization
- 📊 Simple and lightweight interface
- 🔒 Designed with user-friendly controls

---

📱 Requirements

- Android 8.0 or higher
- Compatible Android device
- Shizuku for advanced features
- USB debugging or Wireless debugging may be required
- Root is not required for supported Shizuku features

---
🛠️ Installation

Method 1 — APK Installation

1. Download the latest AxManager APK.
2. Open the downloaded APK.
3. Allow installation from unknown sources if Android asks.
4. Install AxManager.
5. Launch the application.

Method 2 — Shizuku

1. Install Shizuku on your Android device.
2. Start Shizuku using Wireless Debugging or USB Debugging.
3. Open AxManager.
4. Grant the required Shizuku permission.
5. Select the gaming module or optimization you want to use.
6. Apply the settings.

---

🎮 Gaming Modules

AxManager can be used to manage supported gaming modules and Android performance configurations.

Example modules:

🔐 Permissions

AxManager may request permissions required for its supported features.

Permissions can vary depending on:

- Android version
- Device manufacturer
- Selected module
- Shizuku configuration

Only grant permissions that you understand and that are required for the feature you want to use.
